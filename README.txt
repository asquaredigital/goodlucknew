GOOD LUCK CARE — BOOTSTRAP 5.3 WEBSITE

This package updates the Bootstrap homepage to follow the latest Figma mobile frame (Mobile 390px / node 2:271).

KEY UPDATE
- Mobile hero is now image-first: logo/menu header, 248px care image, headline, description, stacked calls to action and click-to-call.
- Desktop hero remains a two-column layout with copy on the left and image on the right.
- The supplied Good Luck Care logo is used in the header and footer.
- Service cards use flexible heights on mobile rather than fixed heights.
- The official CQC location widget supplied by the client is included (location ID 1-2703145341).

RUN LOCALLY WITH XAMPP
1. Extract the ZIP.
2. Copy the good-luck-care-bootstrap folder into C:\xampp\htdocs\
3. Start Apache.
4. Open http://localhost/good-luck-care-bootstrap/

TECHNOLOGY
- HTML5
- Bootstrap 5.3 via CDN
- Custom CSS
- Vanilla JavaScript
- Google Fonts (Inter and Lora) via CDN

NOTES BEFORE PRODUCTION
- Internet access is required for Bootstrap, Google Fonts, Pexels-hosted images and the CQC widget.
- The CQC widget is loaded from the official CQC host. Check it on the live domain and allow the browser to load third-party scripts.
- Confirm that the selected Pexels photograph is the intended image and retain the source/licence information. Stock photography is illustrative and must not be presented as actual Good Luck Care staff or clients.
- The enquiry form remains front-end only. Connect it to a secure PHP handler with server-side validation and spam protection before accepting enquiries.
- Replace any remaining placeholder company, team, testimonial and legal information with client-approved content before launch.
